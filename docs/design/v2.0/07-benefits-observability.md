## 3. 指标字典

| 指标 | 计算/来源 | 展示约束 |
|---|---|---|
| 记忆 payload token | 计最终交付文本，包含标题/来源/围栏/分区 | tokenizer id/version/hash；显示 measured/estimated，不用字符串长度冒充 |
| 单任务节省量/比例 | `baselineMemoryTokens - packMemoryTokens`；比例再除 baselineMemoryTokens | 相同任务及口径配对；baseline=0 则比例 N/A；负收益保留 |
| 汇总 token 节省 | 各任务差值的总和及配对分布；总体比例=`sum差值/sum基线` | 与“各组 token 中位数降幅”分开，禁止平均百分比冒充总体节省；同时报告成功/失败/缺失数 |
| 全链路 token | ingest 抽取/核对 + embedding（单独维度）+ 每次检索/装配的模型调用 + Agent 输入/输出与重试 | 不同 tokenizer/模型分别列，不能混加后称统一精确 token；未观测宿主用量标 unknown |
| 机器调用净成本 | 同任务数/复用次数内，baseline 总费用减 Sedimem 全链路总费用 | 计一次性摄取与后续更新、embedding、失败/重试和所有核对；记录币种/价格版本/缓存计费，不以 payload 降幅直接折算钱 |
| 人工成本与全成本 | 复核条数、耗时；人工单价由用户显式配置后才计算金额 | 未配置人工单价则只报工时，不默认为零，也不宣称包含人工的净收益 |
| 回本次数 | 净累计成本首次不高于 baseline 的实际复用次数；可选按固定平均节省估算 | 标 observed/modelled；每次边际成本无优势时显示“尚未回本/不存在”，不硬给次数 |
| 任务成功率/错误率 | 固定任务判据、同模型/工具权限，逐任务逐次评分；旧事实误用单独统计 | 展示成功数/有效分母与区间；不能用抽取 precision 代替任务成功率 |
| 抽取与证据质量 | 复用 P1a 的 TP/FP/FN、P/R、严重错误、证据解析、对抗拦截/无可记误报 | 继承语料、gold、manifest、annotationMode、split 与裁决来源，不生成第二套评分器 |
| 耗时 | 抽取/核对/检索/装配/回答阶段耗时 + 端到端墙钟；P50/P95 附样本量 | 并发阶段不简单相加当墙钟；无计时则 N/A；真实恢复任务耗时未量测前不宣称节省 |

冻结收益目标仍为 §7.2：同预算混合检索对照，必要证据覆盖不降、memory token 中位数下降 ≥20%、任务成功率不降。20% 不是实测值，也不是总 token/全链路费用下降承诺。机器成本下降和工时下降需各自数据证明，可以为负。

### 3.1 tokenizer 与真实账单的区分

沿用 ADR-101：当前冻结实验计数为 DeepSeek-V3 tokenizer、生成模型单独声明。跨模型时，DeepSeek 计数是可复现实验计量，不是 GLM 真实窗口或计费 token。真实请求 usage（如 provider 返回）、缓存命中/输入输出价格独立保存；无 provider usage/价格时金额只可标 estimate 或 N/A，不能贴“实付”。精确 tokenizer 尚未落地时页面只出 estimated，正式 token 收益验收保持待完成。

### 3.2 观察与反事实的区分

普通一次 pack 回执只能证明本次输入量；如果没有同任务 baseline，不能写“本次节省 X%”。累计看板分别统计 observed、paired-experiment 和 estimated-counterfactual，不把各自估算混成实际节省。宿主未返回 ACK/usage 时，显示 generated/delivered 而非已使用或已省账单。

## 4. 数据契约与结果包（P1b/P1c 新增，planned）

- 一份实验清单 experimentManifest：实验/代码版本、dataset/gold/annotation/split/threshold 版本及 hash、模型与 Prompt、tokenizer、价格与币种、硬件/运行环境、工具权限、范围/asOf、重复次数、随机种子、预算、隐私标签。
- 每条 run/task/arm/repetition 有稳定 ID、输入数据版本、各阶段 token/cost/usage/status、耗时、复核记录、任务结果/证据评分、packHash/回执引用。status 区分 success/failure/missing/degraded；保留失败和重复请求的实际费用，用逻辑运行 ID 去重重放，不抹掉真实重试费用。
- 结果包为原始事件 + 评分产物 + 聚合 JSON + CSV + 人读报告 + 清单/hash。看板和报告只消费同一结果包，聚合规则版本化。字段具体 schema/配额在 P1b 实施前冻结；本文件不谎称现有 runner.meta 已有 usage。
- P1a 既有 meta 的 runId/extractor/processed/zeroOutputScenarios/contentDigest 与 score 输出作为输入适配；原文件和 digest 含义不变。不得用新字段回填旧历史为已测值；可导入旧结果但缺字段明确缺失。
- 当前语料 test 已暴露，展示为 regression/已暴露数据；下一次泛化结论需新的同协议 holdout。使用 model-dual-blinded gold 可展示降级实验，可发布明确标注自动参考来源的实验结果，不能冒充人工真值或客观准确率。两套 gold 的分数不可连线成“提升趋势”。

## 5. 页面与分享边界

- 看板默认先展示实验身份和可信度：数据/标注/计数/usage 口径、实测/估算、是否降级、有效样本、完整性。随后展示成对 token 与净成本，再展示质量与失败案例，不藏负收益。
- 支持按同口径 experiment/version 比较；模型、gold、tokenizer 不同则提示不可直接归因，不能一键拼成排行榜。点击汇总可下钻至任务/阶段及证据授权范围。
- 数字为零、字段缺失、尚未实现是三种状态；N/A 要带原因。无数据页面不能默认显示“节省 100%”。
- 本地查看含私密数据时仍受已有授权、sourceEpoch、撤销与权限约束；公开导出只允许经过检查的合成脱敏实验包。原文、候选、Prompt、trace、路径、密钥不能随默认导出泄露。
- 新事件/结果缓存/导出文件须在数据地图登记保留期、条数字节上限、删除与 verify-delete 路径。已公开下载文件不承诺可远程撤回；统计快照注明数据截止，来源撤销后本地重算/失效。

验收清单：

1. 合成 fixture 检查节省量/比例、汇总与中位数不同口径、零分母、负收益、缺 usage/价格、跨 tokenizer、重复 run/重试费用、摄取与复核摊销、并发墙钟。
2. 同一冻结结果包在看板、JSON/CSV 和 Markdown 中的计数/单位/分母完全一致，重复导入不重复累计；价格版本可回查。
3. 无 baseline 不给节省数字；无宿主 usage 不给真实总费用；estimated/degraded/非人工 gold/样本不足均醒目标出。
4. 配对演示使用相同已接纳记忆和信任策略、回答模型和上限；P1a 规则地板不充当 P1c 混合检索 baseline。
5. 正式报告沿用 ≥30 个未见任务、每组每任务 ≥3 次采样及任务聚类区间；近窗口/BM25/混合/pack 均报告。无记忆组同协议纳入；适用范围与失败案例不能省略。
6. canary/撤销/导出脱敏测试通过；真实浏览器核验看板的异常、空数据/负收益/缺失状态与任务下钻。数据安全/准确性、模型实验及独立审核门禁不因页面完成而豁免。

## 7. 时序指标冻结（2026-11-20，B7.6）

**冻结对象**：不加 LLM 的「纯闸门开销」三个阶段，数值与样本量见
[B7.6 基线报告 §5](../../reviews/v2.0-p1b-b76-2026-11-20/BASELINE.md) 与
`pilot/p1a/config/eval-manifest.json` 的 `thresholds.timingMetrics`（manifestVersion 6）。

| 阶段 | 分母 | p50 冻结 | p90 冻结 | 回归门限 |
|---|---|---:|---:|---|
| R2 ingest | 场景（164） | 0.009 ms | 0.018 ms | p90 ≤ 3×，p99 ≤ 10× |
| R6 decide | 候选（353） | 0.011 ms | 0.017 ms | 同上 |
| R7 commit | 接受候选（277） | 0.001 ms | 0.002 ms | 同上 |

**三条硬规则**：

1. **分栏禁混算**：本表是纯闸门开销，LLM 抽取延迟（B7.7 起）必须单独一栏，两栏不得相加对外报「一次抽取耗时」。
2. **口径随 manifest 版本化**：改分母、改百分位定义、改环境都要走 manifest 修订（版本化 diff + 签署），禁止只改报告数字。
3. **超限须解释**：p90 超 3 倍或 p99 超 10 倍时，评审记录必须写明原因（数据规模/快照实现/并发）与处置，不得静默放过。
