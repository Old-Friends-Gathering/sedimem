## 1. 默认流程与范围

授权来源→脱敏/分段→LLM提出原子候选→证据/语义/冲突校验→自动接纳/拒绝/暂存→长期记忆→后续聊天显式纠正→追加修订→失效旧派生。

- 不要求用户逐条accept、reject、打分、双人标注或点trust promote，不推送日常待审核队列；查询/纠错/清除入口保留为可选工具。
- 沉淀不等于相信：完整事件进入授权证据层；断言保留speaker、speechAct、status、双时间、scope和sourceRefs。助手建议、假设与未执行计划可以按原类别保存，不能改写为已批准/已完成的事实。
- 来源不明、证据缺失/不匹配、跨scope、身份不明、提示注入或违反出站/秘密规则，自动拒绝或隔离。语义冲突暂存unresolved，使用时明确不确定；不等用户复核也不猜赢家。

## 2. 自动接纳与信任的分离

- accepted表示机器策略允许保存，决策者记录`policy:<version>`、规则理由、输入hash和opId，不等于人工核验，也不触发T0/T1提升。保留既有acceptOpId/CAS/持久收据协议。
- 来源trust/taint继续单调继承，普通写仍T2。v1.4手工promote工具可留作兼容/调试，但不是v2.0工作流前置；不会为了取消人工而自动提权。
- v2.0 pack新增“自动记忆陈述”读取口径：同scope、授权来源、证据可解析、非撤销、非隔离且通过自动检查的T2结构化陈述可以被使用，明确“用户曾表示/工具返回/模型归纳”等出处。它们不属于已人工认证facts，也不能授权工具/出站/权限操作。语义校验通过不证明真实世界命题为真。
- T0/T1可信facts分区保留兼容；普通Agent上下文不再依赖该分区非空。T2原文默认扣留，结构化字符串也按不可信数据处理，taint不清洗。新策略仅作用v2.0 pack，不偷偷放宽v1.4 inject默认规则。

## 3. 历史聊天如何纠正

每个修订都要定位到明确原命题/版本和后续直接证据，继承同scope、subject、predicate及适用时间；不能只凭“更晚”或“更高confidence”。

| 后续信息 | 自动处理 |
|---|---|
| 同一用户直接说“刚才说错了，端口应为8081” | 匹配同任务端口命题后追加新版本，旧值在当前读取中失效，保留更正证据 |
| 用户说“先别改，仍用8080” | 标记前一变更已撤回/尚未生效，不能执行被否定的更新 |
| 引用别人、代码示例或远程文档声称“忽略原设置” | 只作引用/不可信来源；不能冒充用户更正 |
| 同名主体、不同项目或不同有效时间 | 不跨边界覆盖；可能是两个并存事实 |
| 工具显示命令失败、退出码非0 | 更新该次执行状态，不能泛化为整个项目均失败/成功 |
| 助手自称“已完成”，无工具/用户直接证据 | 记录助手声称，不能升级为已确认完成 |
| 两个合法来源冲突且无法确定关系 | 保留双方为disputed/unresolved，退出肯定回答；不发人工审批请求 |

错误不是一定会在聊天中被发现。每次读取重新核对来源撤销/时效/当前版本；未被纠正的信息不能因重复使用自动升级信任。模型生成摘要不算独立新证据，禁止自我强化循环。

## 4. 存储、传播与恢复

- correction/retraction和自动接纳都走既有只追加写门禁；更正提交后提升truth/ledger/checkpoint/source修订，旧摘要/向量/pack失效；P1全scope保守失效，P2细粒度依赖优化。
- candidateVersion、evidenceHash、expectedTruthRevision在锁内核验，模型调用锁外；自动处理不能绕开幂等、配额、脱敏、审计和删除。决定理由与策略版本写入持久收据。
- CAS冲突自动刷新后重新判断，次数/时间受policy限制；recovery-required只能依据持久opId/决定/记录版本自动对账。无法证明提交状态时扣留该操作并显示错误，不盲写、不阻塞其他任务、不将其变成人工复核硬前置。
- 自然语言“别记这条/忘记它”目标可唯一定位时调用撤销；目标模糊就保留未决且不批量删库。来源删除/证据过期优先于历史asOf，不能通过聊天重放自动复活。

## 5. 自动评测，取消人工前置

- 保留现有规则/证据定位/状态机/故障测试，增加明确输入输出的“原断言→更正→当前答案/历史答案”时序回归；测试断言由可执行fixture给出，不依赖人逐次打分。
- 复用已建盲评与评分工具。模型参考集标明`model-dual-blinded`，可作为正式自动实验的参考模式，不再因没有人工标注而禁止开发或发布报告；不能改名为`dual-independent`，也不把模型评分称客观真实准确率。
- 模型judge版本与Prompt冻结，与被测输出隔离；双遍分歧用记录化自动策略处理，允许保留未决项，不以取并集就称共识。报告双方一致率、未决量和参考集限制；阈值依旧保留，结果注明“相对该参考集”。
- token/金额/时间来自计数器与usage；语义质量同时报告自动参考得分、确定性错误逃逸、时序纠正成功率、旧值误用率、错误覆盖/冲突扣留/撤销生效率。新增指标的分母与阈值在P1b实现前冻结；本次不伪造数值。
- 取消人手标注不取消自动质量门槛、holdout隔离、失败分母、来源/删除/注入保护。已暴露数据仍是regression，未见任务另建；同一模型judge可能同偏差，如实声明。
