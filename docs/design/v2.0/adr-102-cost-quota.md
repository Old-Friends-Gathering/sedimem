# ADR-102 · 成本与配额闸门（v2.0 规格草案）

> doc-kind: history
> doc-version: 2.0
> status: proposed

状态：**proposed**——随 [v2.0 规格包](README.md) 冻结转 accepted。来源：[future-architecture.md](../../plans/future-architecture.md) §8 可行性、§0.3 规则 7；施工映射 [v2.0-p1.md](../../plans/v2.0-p1.md) §2 冻结决策 7。

## 决策

1. **无配置 = 拒绝出站**：LLM 档基线/抽取运行前必须存在显式成本配置（本地 `pilot/p1a/config/local.json`，gitignore）；缺失即拒绝发起并显式停机，无默认预算。
2. **闸门拦截测试**：无配置、超每日上限、超并发三种情形各有负向用例（协议模拟层），拦截后进程显式停机而非降级续跑。
3. **额度项（初始值写入 manifest/本地配置，可调但须版本化）**：
   - 每次运行最大成本（USD 计价折算）
   - 每日总成本上限
   - 并发请求数上限
   - 每请求重试次数（含退避策略）与重试成本计入当日预算
   - 单请求最大输入/输出 token（按 [adr-101](adr-101-tokenizer.md) 口径计数）
   - 每来源候选数/证据数配额（防止抽取器对单来源倾倒候选）
4. **超限显式停机**：触发任一上限 → 当前运行停止、写入失败枚举 `policy-blocked`、提示人工复核配置；不自动清零、不静默继续。
5. **成本预占/结算幂等（草案级，真实调用前生效）**：预占记录带 runId；结算（成功/失败/超时）恰好核销一次；崩溃后以预占+结算记录对账，孤儿预占超时释放。
6. **LLM 档「配置就绪」验收**：本 ADR 全部条款在闸门代码生效 + **用户显式确认成本**（对话确认，留痕于执行记录）——两者齐备才允许第一次真实调用；在此之前 LLM 档只产出配置就绪证明，不伪称成绩。

## 出站安全（future-architecture §0.3 规则 7）

| 条款 | 内容 |
|---|---|
| 目的地白名单 | 出站请求只允许发往配置声明的 endpoint（如 open.bigmodel.cn）；白名单外一律拒绝 |
| 发送字段冻结 | 每类请求（基线抽取/评测）显式声明发送字段清单；清单外字段（含环境变量、本机路径、其他 scope 内容）不得入 payload |
| 脱敏前置 | 发送前过 v1.4 既有脱敏门（patterns.js 全量规则）；脱敏失败 = 拒绝出站 |
| finish_reason | 识别 `length`（截断）与 `tool_calls` 等终态；截断响应标 `token-truncated`，不解析半截输出（[01-candidate-schema.md](01-candidate-schema.md) §3 失败枚举） |
| 增量 chunk 开销 | 流式响应的 JSON 重建、覆盖格式与证据引用开销计入输出 token 预算；chunk 重组必须完整拼接后再解析，禁止逐 chunk 边收边解析 |

## 与现行 v1.4 LLM 层的关系

v1.4 LlmPort（provider 配置、policy.js 限额）保持不变；本 ADR 是 **pilot 工具自身的闸门规格**，不修改 v1.4 运行面。P1b 施工把闸门语义并入 v2.0 写路径时以本文件为准。
