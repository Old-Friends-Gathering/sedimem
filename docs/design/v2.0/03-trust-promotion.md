# 03 · 自动接纳与来源信任（r2）

> doc-kind: contract
> doc-version: 2.0
> status: planned

2026-11-18 用户取消日常人工复核，当前权威为 [08自动记忆与历史纠正](08-auto-memory-and-correction.md)。本r2替代旧冻结r1；[旧版快照](history/2026-11-18-manual-r1/03-trust-promotion.txt)只供追溯，P1a旧测试不能证明r2已实现。

## 1. 默认无人值守

候选通过证据/范围/语义/冲突规则后由policy自动accept；拒绝或未决也由policy记录，不要求用户逐条操作。accepted只表示允许保存，来源trust仍T2且taint不减；不自动promote为T0/T1。

v2.0 pack可以消费受证据约束且来源明确的T2结构化记忆陈述，显示出处/不确定性，不宣称人工认证、不授予工具权限。T0/T1保留兼容，不再作为普通记忆可用的前置。现行v1.4普通写/手工promote行为不变。

## 2. 后续纠正

后续直接用户更正/撤回或可定位工具状态变化经身份/主体/时间校验后自动追加修订；引用、助手推断、不同scope不能覆盖旧记录。无法消解冲突时保存disputed/unresolved，不肯定输出、不生成待人工审批队列。

## 3. 传播与验收

摘要继承来源最低信任、taint并集；更正/撤销/证据过期使所有依赖过期。必须补自动接纳不提权、T2可读但不授执行权限、来源删除、两进程/重放、聊天纠错时序和未决冲突的保护测试。r2实现前重新冻结1a/1b/5相关规格，不沿用r1“人工两次操作”验收。
