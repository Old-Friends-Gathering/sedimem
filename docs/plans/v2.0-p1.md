### D2 标注规范（并入 `04-scoring-and-splits.md` 或独立 `06-annotation-spec.md`；`05` 已被 threshold-manifest 占用）

- gold 字段：角色/类型/适用范围/状态/双时间/证据 span/应拒绝理由；「无可记」场景标注理由。
- 双独立标注流程：两份互不可见 → 维护者裁决 → 版本化；第二标注人必须是**人工且独立**——模型辅助标注可声明但永不构成独立标注人；仅同一人重复标注不称独立。
- **单人现实**：pilot v0 用单标注 + 声明 pilot；出口级 gold 冻结须第二标注人到位（用户决策项——它是 P1a 出口的硬前置，只不阻塞 P1a 工具链）。
- 防泄漏：标注者不得看打分器实现/基线输出后再标 gold（评分器隔离的反向约束）。

### D3 pilot 语料 v0 + 校验工具

- 规模（pilot，非出口）：≥40 场景（中/英各 ≥12，含混合语言 ≥4）；gold claims ≥60；无可记 ≥6；对抗 10 类各 ≥3（否定/建议未接受/后续纠正/条件假设/工具失败/跨项目同名/跨段指代/时区相对日期/注入/截断缺口）。
- 场景来源：**合成脱敏**。参照真实结构（任务账本混合历史待办、多轮纠正、工具失败回显）人工编写；禁止粘贴真实 transcript/SN/邮箱/本机路径入仓。
- `pilot/p1a/tools/corpus-validate.mjs`：schema 校验（场景/gold/对抗标签/语言配额/家族切分/近重复跨集检测 Dice ≥0.85 判重口径与主库一致）→ JSON 报告；报告按语言与错误类**分项**输出（场景可多标签）；`node --test` 保护测试。
- 验收：validate 全绿 + 语料抽查（维护者逐条读过 dev 侧 pilot）。

### D4 基线 runner

- 输入：`pilot/p1a/config/local.json` 指定的本地授权 transcript（验证轨）或 corpus 内合成场景（评测轨）。
- 管线：capture 适配器（DSH transcript JSONL → 事件流，含 role/speaker/tool 状态/eventId/时间）→ 规范化+脱敏 → 按 token 窗口切段（tokenizer 按 ADR-101；无精确 tokenizer 时显式 estimated 并不出正式成绩）→ 抽取。
- 两档：**规则基线**（确定性、零 LLM，永可跑）；**LLM 基线**（仅当 ADR-102 配置就绪 + 用户显式确认成本后）。
- 输出：候选 JSONL（按 01 schema）+ 机器校验报告（对照 gold TP/FP/FN + 七类严重错误 + 三层计数 + 必报三项钩子：拦截率、每场景复核数量/耗时、无可记场景误报率）。
- 复核 CLI 骨架：`list/show/diff` 只读三命令（完整 accept/reject/status 流程留 P1b，避免提前固还没审核过的交互语义）。
- 幂等最小实现：游标/快照按 01 规格；kill/restart 重放测试 ≥1 条真实路径。
- 验收：合成语料上规则基线可复现报告；LLM 档仅出配置就绪证明，不伪称成绩。

## 4. 语料与标注红线（重申）

1. 仓库语料一律合成脱敏；真实 transcript 只在本地验证轨，路径不入 git。
2. 无独立第二标注人时，一切结果标 pilot；不得写「gold 验收通过」。
3. test 场景与 gold 冻结前不进打分器视野；打分器不得读 gold 之外的答案源。
4. 对抗样例的「模型被拦住的错误」与「逃逸错误」分开计数。

## 6. tokenizer ADR 预研结论（供 adr-101 决策）

| 候选 | 精确性 | 许可/分发 | 风险 |
|---|---|---|---|
| GLM 系列（zai） | 待查证：无公开精确 tokenizer 则不可用 | 未定 | 与生产模型一致但可能无精确实现 |
| DeepSeek-V3/R1 tokenizer | 公开精确（HF tokenizer.json） | MIT，可 vendor 数据文件 | 与实际生成模型（GLM）不一致，跨模型 token 差异需书面声明 |
| tiktoken 系列 | 精确但不含 GLM/DeepSeek | Apache-2 | 与目标模型不匹配 |

推荐：**首个正式效果实验目标组合 = DeepSeek tokenizer 计数 + 生成模型固定为实验声明中的模型**；若查证 zai 有公开精确 tokenizer 则优先 GLM 自身。附加约束：
1. 「查证 zai 是否有公开精确 tokenizer」是 adr-101 定稿的**前置任务**（产出查证记录），不是待定项；

3. 若落定跨模型组合，效果实验结论须限定「仅在该 tokenizer 计数口径下成立，不外推到真实部署窗口」。
