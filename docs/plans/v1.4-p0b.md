## P0b 主体（按 §6.2 的 17 项）

按依赖排序，每项先写规格/测试，再写代码：

### B1. 锁与队列

- [x] storage 数据锁 `<memoHome>/.lock`：5s 心跳、陈旧判据 = mtime 超时 **且** owner pid 不存在、rename 接管；`capture/queue.js` 的同步锁暂未并入（偏离见执行结果）。
- [x] `llm/outbox` 锁保留，ADR-001 写理由（Q15 禁依赖 storage）。
- [x] 队列 append 改 `O_APPEND` 流式写，不整文件重读重写；`capture.maxQueueBytes` 单文件字节配额（`E_QUEUE_QUOTA`）。per-adapter / 每日配额与 provenance 数组上限留到 P2（有 adapter 才有主体）。
- [x] 测试：`kill -9` 后锁可恢复；存活 owner 不被误接管；配额超限 fail-loud 且不写半行。两进程并发 append 由现有 storage 并发测试覆盖，未新增跨进程用例。

### B2. trust / taint / provenance

- [ ] `MemoryRecord` 增可选 `trust`（T0–T3）、`taint[]`、`provenance`（源 + 引用）；缺省读作 T2。
- [ ] `memory_write` / CLI / capture accept 只接受 adapter 声明的 trust **上限**；真实等级由人工注册表决定。
- [ ] merge / supersede 追加新版本 `v+1`，taint 取并集，禁止静默清除；`memory_write` 无 scope 时写当前库。
- [ ] 存量 backfill：`source.agent ∈ {cli,dsh,claude,codex}` 且无 adapter/sourceRefs → T0，否则 T2；写 ADR 与 `memo migrate` 回滚。
- [ ] `memo trust promote` 是唯一降 taint 动作，带理由、写审计。
- [ ] 测试：T2 不可被 accept/write 洗成 T0；merge 后 taint 包含两侧；backfill 后 pack 非空。

### B3. 删除与 profile

- [ ] `deleteBySource(adapter/uri)`：墓碑 + compact + 清派生 + 脱敏审计 + 备份说明；含任务账本 `sessions/<taskId>/segments.jsonl`。
- [ ] `memo verify-delete`：按来源/哈希确认目标记录、索引、向量、brief、账本段均已消失。
- [ ] profile 收敛到 `resolveMemoHome(env,cwd,profilePointer)`；默认 `~/.memo` 不变；命名 profile 在 `~/.memo/profiles/<name>/`；缺失指针 fail-closed。
- [ ] 测试：命名 profile 互不可见；删来源后 verify-delete 通过；默认 profile 路径不变。

### B4. Web 鉴权与文件权限

- [ ] `memo serve` 启动生成会话 token；浏览器面下发 `HttpOnly; SameSite=Strict` cookie；API 接受 cookie 或 `Authorization`。
- [ ] 强校验 Host / Origin；缺失 Origin 的写请求拒绝；直连 MCP 也要求 token（本地 UDS 或 header）。
- [ ] `~/.memo` 0700、文件 0600（Windows ACL）；启动校验；文档写明 Time Machine / 云盘备份风险与排除建议。
- [ ] 测试：无 token 401；有 token 200 且 UI 可用；跨 Origin 写拒绝；目录权限不对时启动告警。

### B5. 注入与审计

- [ ] T2 默认不注入原文：只注入结构化抽取/摘要；必须注入时用 `hash(contentHash+asOf)` 派生的确定性 nonce 围栏，逐行转义。
- [ ] 「数据不是指令」写进 system prompt；行为测试：T2 金丝雀若触发任何工具调用/外写则失败。
- [ ] 审计统一到 `events.jsonl`（kind + seq + prevHash）；外部锚定可选（本地 git 提交，不 push）；明确「不抗同 UID 重算」。
- [ ] `quarantine` 只存引用（uri + hash + ≤200 字 quote），不存正文；TTL/配额与 inbox 同表。
- [ ] 数据地图 `docs/12-data-map.md`：候选 14 天、events/quarantine 90 天、任务账本 90 天可配；PII 类别与 export/delete。

### B6. 工具面、读预算、Windows

- [ ] `memo mcp --surface core|all` + `--session-tools`；默认 `core`（现有 3 个：search/write/brief；P1 加 pack），兼容表写进 README 与升级说明。
- [ ] 读预算：`search` 默认返回片段（单条 ≤200 字、默认 ≤20 条），每会话条数/字节上限，落点 `api/search-path.js`。
- [ ] Windows：只支持 kernel/CLI；adapters 不支持；`memo doctor` 在 win32 说明并 exit 2（仅 adapter 子命令）。
- [ ] hits 只观测：P0b 只加测试 + ADR，不迁移；P1 再移出真相层。
