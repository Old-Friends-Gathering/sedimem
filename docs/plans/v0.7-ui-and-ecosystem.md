# v0.7.0 施工图（Part II）：UI 改版与生态补齐

状态：待用户批准（尚未实现）。
关联：`docs/plans/v0.6-memory-quality-and-session.md`（Part I：写侧契约 / 临时记忆库 / 分库粘性）。
调研依据：`docs/research/ui-template-2026.md`、`v06-vs-alternatives-2026.md` §4.

> **为什么单独成 v0.7.0**：Part I 已在改写入契约 + 新增 session 数据模型，
> 再叠加「UI 全面换装 + 写 API + 五个导入器」会让一个版本变成三件事，
> 门禁与审核都会失效（v0.4 一次塞七项能力就是教训：审出 6 个阻断项）。
> 所以 Part II 独立发版，但**计划同源、接口互相咬合**：Part I 的 session 数据一落地就是 v0.7 UI 的数据源。

## 1. 要解决的三条生态短板（用户原话）

| 短板 | 现状 | v0.7 目标 |
|---|---|---|
| **无人类直接编辑入口** | 观察台只读（`memo serve` 无写端点），改记忆只能靠 agent 或 CLI | 本地写模式：表单编辑 = **追加新记录 + supersede 旧的**，带版本历史与审计 |
| **无导入/迁移** | 只有 `migrate-dsh-memory`（自家 v0.1 遗留） | 五个导入器：AGENTS.md/CLAUDE.md、basic-memory、Obsidian、mem0 导出、Cline memory-bank |
| **可视化只到 mockup** | 手写 canvas 折线 + 自研 3D 图谱，样式是手搓 CSS | 复用 Tabler 组件体系，图表换 uPlot，图谱保留自研（见 2.2） |

## 2. 选型（定稿，含「为什么不是别的」）

### 2.1 结论

**Tabler CSS（自托管单文件）+ uPlot + 保留自研图谱 + Lucide SVG sprite + system-ui 字体。**

### 2.2 逐项裁决

| 组件 | 选择 | 体积 | 为什么不用替代品 |
|---|---|---|---|
| 布局/组件 | **[Tabler](https://github.com/tabler/tabler)**（MIT，只用 CSS，不用其 JS） | `tabler.min.css` ≈ 694KB 未压缩（gzip 后约 60–80KB） | Bootstrap 5 观感陈旧且默认组件少；Pico/Simple/MVP 是 classless，做「侧边栏 + 表格 + 表单 + 徽标」要写大量自研 CSS；DaisyUI/shadcn/Tremor 都要构建链（Tailwind/React），违背零构建 |
| 图表 | **[uPlot](https://github.com/leeoniya/uPlot)**（MIT） | iife+CSS ≈ 45KB | Chart.js 体积大 3 倍且 canvas 重绘慢；ECharts 1MB；ApexCharts 需构建；uPlot 原生支持「null 跳过」（我们卫生页趋势正需要），性能最好 |
| 图谱 | **保留自研**（599 行 canvas）+ 可选借 `d3-force-3d` | 自研 0KB；d3-force-3d ≈ 30KB | 3d-force-graph 带 three.js ≈ 1.5MB；cytoscape/sigma 面向 2D 大图与我们的 3D 球壳投影不匹配；**自研图谱是本项目的差异化，替换得不偿失**（但把力导向算法抽出去复用 d3 的，可减少自研物理代码） |
| 图标 | Lucide 常用 20 个手拷成 SVG sprite | <8KB | 图标字体要多一份字体文件；npm 包引入违背零构建 |
| 字体 | `system-ui` 栈 | 0 | 离线可用，不需要下载字体 |

### 2.3 vendor 政策（**必须写死，否则「零依赖」变成谎话**）

`versions/v0.7/ui/vendor/` 只允许放**静态资源**，且每个文件必须满足：

1. 目录内 `VENDOR.md` 登记：`文件 / 版本 / 上游 URL / LICENSE / sha256`；
2. 同名 `LICENSE`（或 `LICENSE.txt`）随文件入库；
3. 门禁 **Q13** 校验：文件 sha256 与登记一致、LICENSE 存在、`grep -c "<script src=\"http"` == 0（**禁止 CDN**）；
4. 运行时**零 npm 依赖**这条不变（package.json 依赖字段仍为空）——vendor 是随仓库分发的静态文件，与「运行期依赖」是两件事，本版会在 README 与 `docs/00-principles` 里把这句话改写清楚，避免自欺。

## 4. 可编辑的安全设计（这是本版最容易做错的部分）

### 4.1 默认仍只读

- `memo serve` 默认 `--readonly`；写模式需显式 `memo serve --write`，并要求 `MEMO_WRITE_TOKEN`（32 字节随机，写进 `~/.memo/serve-token`，权限 0600）；
- 只允许 `127.0.0.1` / `::1`（已有 `isLoopbackHost()` 运行时断言），**不提供 `0.0.0.0` 开关**；
- 所有写请求：`Authorization: Bearer <token>` + `Origin` 校验（不同源直接 403）+ `Content-Type: application/json`。

### 4.2 编辑语义：追加而非覆盖

编辑 = **append 一条新记录 + 把旧记录 supersede**，永不原地改（append-only 是立身之本）。

- 请求体带 `ifMatch: {id, validFrom}`；服务端比对当前 active 记录，不一致返回 **409 + 当前版本**（前端展示「别人改过，刷新后重试」）；
- 同 `subject/predicate/value` 且无内容变化 → `noop_same_value`（不产生新版本）；
- 删除 = `forget`（tombstone），UI 上叫「失效」而不是「删除」，并显示「可 30 天内恢复」。

### 4.3 审计

每次 UI 写：`events.jsonl` 追加 `{op:'ui_edit', scope, id, detail:{action:'write|supersede|tombstone', prevId, tokenId}}`；
`source.agent='ui:local'`（走 v0.1.1 的 agent 自由标签规则）。
`memo doctor` 增加「最近 24h UI 写次数」，异常突增可发现。

## 5. 导入器（五个源，全部 `--dry-run` 优先）

统一契约：`memo import <source> <path> [--dry-run|--apply] [--scope] [--map k=v]`

| 源 | 映射 | 坑（必须处理） |
|---|---|---|
| `AGENTS.md` / `CLAUDE.md` | `## 段标题` → `subject`；段内要点逐条 → `kind=pref`/`decision`（标题含「禁止/不要/必须」→ decision） | 指令型文档不是事实集合，**默认只导「约定」类段落**，代码片段/命令示例跳过；超长段自动切句并给 `splitSuggestion` |
| `basic-memory` | frontmatter（title/tags）→ 记录头；`- [category] observation` → 一条记录 | 关系（Relations）不导（我们没有图存储），只记到 `tags` |
| Obsidian vault | `# H1` → subject；列表项 → 一条；`[[wikilink]]` → `tags` | 附件/图片跳过；同名笔记冲突走 dedupe 候选而不是覆盖 |
| mem0 导出 JSON | `memory` 文本 → `text`；`metadata` → `kind/tags` | 导出无 scope 概念，需要 `--scope repo:<name>` 显式指定 |
| Cline memory-bank | 六文件（projectbrief/productContext/systemPatterns/techContext/activeContext/progress）→ 前四个进主库 `decision`/`pref`，`activeContext`/`progress` 进 session 库（若 Part I 已存在） | `activeContext` 是易腐内容，**默认不导进主库** |

dry-run 报告：`新增 N / 重复跳过 M / 需人工确认 K`；`--apply` 后写一条 `events` `import` 记录，附带源文件 sha256（可重放、可审计）。

## 8. 风险与回滚

| 风险 | 处理 |
|---|---|
| Tabler 体积（694KB）让首屏变慢 | 只 vendor `tabler.min.css`（不引其 JS 与图标字体），实测首屏 <150ms（本地静态）；必要时按需裁剪未用组件（PostCSS 手工裁剪不做，改为直接接受体积） |
| 写 API 成为攻击面 | 默认关闭 + token + loopback + Origin 校验；写端点全部走同一 `handleWrite()` 单入口，便于审计与限流 |
| 编辑破坏 append-only 语义 | UI 只暴露 append/supersede/tombstone 三个动作，**无 UPDATE/DELETE 端点**；I43 用测试锁死 |
| 导入产生垃圾记录 | 默认 `--dry-run`；`--apply` 前必须看报告；导入记录带 `import:<source>` tag，可一键 `forget` 回滚 |
| 一次性改太多导致审核失效 | W6–W10 每波独立 PR + 双审核；UI 视觉用截图对比，不靠人眼说了算 |

## 9. 明确不做

1. **不引入 SPA/React/Vue**，不引入打包器（保留「打开 index.html 就能跑」的能力）；
2. **不用 CDN**（离线优先，CDN 断网即白屏）；
3. **不做云端同步/多人协作**（定位是本机个人）；
4. **不做可视化拖拽编辑**（节点拖拽重排只影响布局，不改数据）；
5. 不追 IDE 插件生态（v0.6 的取舍延续）。
