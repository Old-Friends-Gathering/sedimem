## 自回复 2（讲设计取舍 —— 这条给懂行的人看，带图 `x-arch.png`）

```
The design bet: separate truth from derived.

Truth = append-only JSONL. Never mutated.
Everything else (FTS5 index, graph, LLM titles, briefs) is derived — delete it, regenerate it.

That's why I dare let an LLM write summaries: it can't corrupt the source.
```
