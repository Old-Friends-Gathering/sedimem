## 正文（图卡版，≈830 字）

做 AI 编程最烦的不是它写错代码，是**每次开新窗口都要从头讲**：项目在哪、构建怎么跑、上次那个坑为什么不能踩。

写 CLAUDE.md 也救不了——越写越长，最后全被挤到注意力末尾。

所以我自己做了个本地记忆库 **sedimem**。这周把它最后两块拼上了：**LLM 总结层**和**任务库**。

---

**① 它不靠「让它记住」，靠只追加**

每条记忆就是一行 JSONL：永不原地改，改主意也只是追加新版本 + 给旧的打失效标记。

所以它记错了我能翻回去，而不是「AI 记忆又乱码了」。

**② 索引、图谱、摘要全都可以删光重建**

真正不能丢的只有那一层原始记录。索引坏了？删掉重跑。摘要写歪了？重算。

这让我敢开 LLM 写标题——反正它是派生层，坏了重来。

**③ 任务库：按任务分，不按会话分**

多 agent 一起干活时，一个任务会被 DSH / Codex / Claude 接力好几段；按会话切，上下文就碎了。

所以按任务开库：干活时它自己记（做到第几步、卡在哪、下一步干嘛），收工时只有 decision 和 gotcha 晋升回主库，其余丢弃，并自动写一份交接文档。下一个 agent 接着干就行。

**④ 一个 MCP server，三个客户端共用**

DSH / Codex CLI / Claude Code 读的是同一份 JSONL。换工具不用重新喂记忆。
