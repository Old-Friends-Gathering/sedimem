## 正文

AI 会忘记你，它不会。🧠

每次重开 AI 编码助手，都得重新教一遍：项目在哪、构建怎么跑、上次那个坑为什么不能踩。写了 CLAUDE.md，越写越长，最后还是被挤到注意力末尾。

所以我自己做了个本地记忆库 **sedimem**（sediment + memory，沉积岩那个沉积）。这周补上最后一块：**LLM 总结层开了**。

---

**这次上新了什么**

🧾 **LLM 接管标题摘要**
以前标题是 `subject/predicate` 拼的（"strata · index" 这种），现在模型写人话：「检索后端可选 memory 或 sqlite」。关了 LLM 一切照常，只是少层摘要。

🗂 **记忆中心九页（浏览器里看，只读）**
今日变化 / 3D 图谱 / 搜索 / 卫生 / 编辑 / 导入 / 会话 / 交接 / 设置。图谱点节点看原文；卫生页专门盯重复、冲突、过期。

🧹 **记忆体检：33 条揪出 5 条垃圾**
LLM 标出测试脚手架残留（"冒烟决策2""验收 accept06 通过"）和同一件事的两种说法，我逐条核对后才删/合并 → 33 变 30，冗余率归零。

🔌 **一个 MCP server，三端共用**
DSH / Codex CLI / Claude Code 读同一份 JSONL，换工具不用重新喂。

---

**和常见方案不一样的地方**

· 真相层是 append-only JSONL：只追加、永不原地改，任意时点可回溯
· 索引、图谱、摘要全是派生层：删光能一键重建
· 零运行时依赖，数据只在 `~/.memo/`，不联网也能用
