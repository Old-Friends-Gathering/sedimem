## 正文

AI 会忘记你，它不会。🧠

每次重开 AI 编码助手都得重新教：项目在哪、构建怎么跑、上次那个坑为什么不能踩。CLAUDE.md 越写越长，最后全被挤到末尾。

所以我做了个本地记忆库 **sedimem**。这周补上最后两块：**LLM 总结层**和**任务库**。

---

**这次上新了什么**

🧾 **LLM 接管标题摘要**
以前标题是 `subject/predicate` 拼的（"strata · index" 这种），现在模型写人话。关了 LLM 一切照常，只少层摘要。

🗂 **记忆中心九页（浏览器里看，只读）**
今日变化 / 3D 图谱 / 搜索 / 卫生 / 编辑 / 导入 / 任务 / 交接 / 设置。图谱点节点看原文，卫生页盯重复与过期。

🧹 **记忆体检：33 条揪出 5 条垃圾**
LLM 标出测试残留和同义重复，我逐条核对后才删/合并 → 33 变 30。

🧠 **任务库：按「任务」分，不按「会话」分**
过程性内容（下一步做什么、刚踩了什么坑）不该进长期库，但也不该按会话切——多 agent 联合开发时一个任务会被好几个 agent 接力，按会话切就把上下文切碎了。所以按任务开库：start → checkpoint（固定 8 段，也能接 DSH 压缩摘要）→ close。**只有 decision 和 gotcha 晋升回主库**（带标签可溯源），其余丢弃 + 自动写交接文档。

🔌 **一个 MCP server，三端共用**
DSH / Codex CLI / Claude Code 读同一份 JSONL，换工具不用重喂。

---

**和常见方案不一样的地方**

· 真相层是 append-only JSONL：只追加、永不原地改，任意时点可回溯
· 索引 / 图谱 / 摘要都是派生层，删光能重建
· 零运行时依赖，数据只在 `~/.memo/`，可离线
