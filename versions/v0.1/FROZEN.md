# v0.1 线已冻结（0.1.2）

这个目录是 **v0.1 大版本的最终快照**，只作为历史与对照保留，不再接受改动。

- 版本号：0.1.2（质量/安全门禁 + 开源品牌）
- 能力范围：核心记忆层（append-only 真相层 + 派生索引 + brief）、四条卫生路径、MCP/CLI 双入口、注入式评测 I1–I12
- **没有**：Web 观察台、SQLite FTS5 后端、curate 任务包、多分库浏览 —— 这些是 v0.2 线的工作，见 `versions/v0.2/`
- 门禁与评测只跑 `versions/CURRENT` 指向的版本；本目录的测试不再随 CI 跑（保留是为了「当时的代码长什么样」可查）

版本目录规则：**大版本换目录（v0.1 → v0.2），小版本在同一目录内递增（0.2.0 → 0.2.1）**。
